# 월간 거시 통합 점검

주간 리포트가 **시장**을 본다면, 이 글은 **펀더멘털**을 본다. 역할이 겹치지 않게 쓴다.
관점은 블로그 전체와 같다 — **안전마진 기반 가치투자자**.

## [STEP 1] 데이터 수집 (스크립트가 전부 한다)

```
<MacroEconomy venv python> scripts/macro/fetch_and_chart.py {발행일}
```

- 결과: `content/reports/_parts/{발행일}/macro-data.md` (수치 요약) + `charts/*.png` (차트 13종)
- **수치를 직접 웹서치로 찾지 않는다.** 이 글의 모든 숫자는 ECOS/야후 원데이터에서 나온다.
- 스크립트가 실패하면 그 자리에서 중단하고 원인을 보고한다. 추정값으로 글을 쓰지 않는다.
- `macro-data.md` 맨 위의 **계열별 최신 시점** 표를 반드시 먼저 읽는다. 계열마다 최신 시점이
  다르므로(월 지표는 전월, GDP는 두 분기 전인 경우가 흔하다) 본문에 시점을 명시한다.

## [STEP 2] 본문 집필

`macro-data.md` 의 표에서 **움직인 것**을 골라 쓴다. 전체를 나열하지 않는다.

구성:
- **0. 한 장 요약** — 6축 현황/방향 표 + 핵심 서사 한 줄
- **1. GDP** — 실질 vs 명목, 디플레이터, 성장 기여도, 산업별
- **2. 수출입** — 총액·무역수지, 상대국, **금액/물량/단가 분해**, 교역조건
- **3. 심리지표** — BSI 실적/전망, 제조업 가격 BSI(원자재·판매가격·채산성), CSI
- **4. 물가** — CPI/근원/PPI, PPI-CPI 격차
- **5. 금리** — 기준금리·대출금리·스프레드, 주요국 정책금리, 미국채 커브
- **6. 환율·대외부문** — 원/달러 vs 달러인덱스, 국제투자대조표
- **7. 종합 판단** — 안전마진 관점 + **다음 달 체크리스트**(지표/현재값/경계수준/의미)
- **데이터 출처와 작성 기준** — 사용한 통계표 코드, 산출식, 기준 시점

각 축마다 표 → 차트 → `> **인사이트**` 블록(왜 중요한지, 투자 판단에 어떤 의미인지) 순서로.
인사이트는 **데이터가 뒷받침하는 것만** 쓴다. 숫자 없는 전망은 쓰지 않는다.

## [STEP 3] 발행 형식으로 조립

1. 차트를 `content/reports/{발행일}/charts/` 로 복사한다.
2. 본문의 이미지 경로는 `{발행일}/charts/01-....png` 형식이어야 한다
   (글 HTML은 `dist/posts/` 에 놓이므로 상대경로 기준이 그렇다).
3. 글 맨 위에 H1을 쓰지 않는다 — 빌드가 frontmatter `title` 로 제목을 만든다.
4. frontmatter:
   ```
   ---
   title: 거시경제 통합 점검 — {그 달의 핵심 서사}
   date: {발행일}
   tags: [거시, 한국은행, GDP, 물가, 금리, 환율]
   description: {가장 중요한 수치 2~3개를 담은 한 줄}
   ---
   ```
5. `content/reports/{발행일}.md` 로 저장한다.

## [STEP 4] 검증 후 발행

```
npm run build      # prebuild 로 개인정보 게이트 자동 실행
```

- 개인정보 게이트 또는 이미지 게이트가 실패하면 **발행을 중단**하고 원인을 보고한다.
- 통과하면 커밋 + 푸시 → GitHub Pages 자동 배포.
- 커밋 메시지: `{YYYY}년 {M}월 거시 통합 점검 발행`

## 주의

| 항목 | 규칙 |
|---|---|
| 통계표 혼동 | `403Y001`은 **수출금액지수**, 물량지수는 `403Y002`다. 단가 = 금액 ÷ 물량 |
| `901Y121` | `통계항목명2`는 품목이 아니라 **상대국**이다 |
| GDP 시점 | 분기 지표는 늘 두 분기 전이다. "최신 GDP"라고 쓰지 말고 분기를 명시한다 |
| 개인정보 | 개인 자산 절대금액 금지(비중·수익률만). 이 글은 포트폴리오를 다루지 않는다 |
| 면책 | 템플릿 푸터에 자동 삽입되므로 본문에 따로 쓰지 않는다 |
