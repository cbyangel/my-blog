## 2. 모든 상세 섹션의 첫머리
섹션 제목 바로 아래에 인용 블록 하나로 핵심 3줄을 둔다.
```
> **이 섹션 핵심**
> - (가장 중요한 사실 + 숫자)
> - (그게 내 계좌에 뜻하는 것)
> - (지난주 대비 바뀐 것)
```

## 3. 문장
- **결론을 먼저** 쓰고 근거를 뒤에 쓴다. 소제목도 결론형으로("금리가 내렸다 — 채권이 버텼다").
- 한 문장에 한 가지. 한 문단은 3~4문장 이내.
- "높다/낮다" 대신 기준과 비교한 숫자("평균 16배보다 1.4배 높다").
- 전문용어는 **처음 나올 때 괄호로 짧게 풀어 쓴다.** 예: 정배열(짧은 평균선이 긴 평균선 위에 있는 상승 구조), 이익수익률(PER을 뒤집은 값, 주식의 "이자율"). 자세한 설명은 끝의 "용어 풀이"에 맡긴다.
- 영어 약어는 처음에 한글을 함께 쓴다: PCE(개인소비지출 물가), FOMC(미국 금리 결정 회의).
- 감탄·과장 금지. 확인 못 한 숫자는 "수집 불가"로 쓰고 지어내지 않는다.

## 4. 분량과 표
- 한 섹션의 표는 **핵심 표 2~3개**로 줄인다. 시계열·세부 지표 표는 섹션 끝 "상세 지표" 소제목 아래로 모은다(부록 성격).
- 같은 숫자를 여러 섹션에서 반복 설명하지 않는다. 요약에서 한 번, 해당 상세 섹션에서 한 번.
- 표는 모바일에서 가로 스크롤되므로 열은 6개 이하를 권장.

## 5. 계좌 운용 방식 구분 (반드시 지킴)
- 연금저축·IRP·퇴직연금 = **자산배분 + 리밸런싱**. 하락은 리밸런싱 기회. 추세 신호로 매수를 미루거나 매도를 권하지 않는다.
- ISA = **추세추종**. 추세가 꺾이면 축소, 살아나면 추가.
- 상세 규칙은 agents/etf-analysis.md 0장.

## 6. 개인정보
- 절대금액 금지. 비중(%)·수익률(%)·괴리(%p)만. ETF 1주 가격(원)과 거시 수치는 괜찮다.
